安装 停一下 · 视频解惑

插件免费，模型使用消耗你自己的 WorkBuddy 账号额度。首发环境：macOS、Chrome 116+、Node.js 22+ 与已安装并登录的 WorkBuddy。

Chrome 商店版本尚未公开发布。下方为手动安装方式；商店审核状态会在完成提交后更新。不要把其他来源的扩展当作本产品安装。

安装本机连接器

下载正式发布包并解压，双击 安装本机连接器.command，或在文件夹打开终端运行 node scripts/install-host.mjs。连接器仅调用已安装的 WorkBuddy，不读取账号密码或 API 密钥。

下载 macOS 安装包

安装浏览器扩展

  1. 在 Chrome 打开 chrome://extensions/，开启开发者模式。
  2. 点击“加载已解压的扩展程序”。
  3. 选择发布包内的 release/chrome-extension 文件夹。
  4. 将 停一下 · 视频解惑固定到工具栏。

第一次提问

打开视频、暂停，点击扩展图标，确认顶部画面和时间点。阅读并勾选数据发送授权，输入问题。处理时可点击“停止”，完成后可继续追问。

无法连接

确认 WorkBuddy 已登录、账号额度可用，安装器运行成功，且 Node.js 没有被移除。移动源码目录不会影响已经复制到本机应用支持目录的连接器。首次安装后可关闭侧栏并重新打开。

启用语音

此功能需要 Python 3.10+。运行 node scripts/install-audio.mjs /path/to/python3，首次会安装依赖并下载开源识别模型。重新打开侧栏后，点击“补充这段声音”，确认后回放并采集短片段，在电脑上识别语音；不额外调用转写 API。识别结果仍可能有误，应结合原片段判断。

找不到视频或字幕

将播放器滚动到可见位置，再点击工具栏图标。跨域嵌入、专有播放器或受保护内容可能无法读取。字幕不提供时仍可解释画面，或主动补充声音片段；没有实际语音转写时，不会假装已经听过声音。

卸载

在 Chrome 扩展管理页移除 停一下 · 视频解惑，并运行发布包中的 node scripts/uninstall-host.mjs，只删除本产品的本机连接器。
